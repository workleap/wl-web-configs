# Browserslist

## Supported browsers

You can find an exhaustive list of the browser versions included with this shared configuration on [https://browsersl.ist](https://browsersl.ist/#q=last+2+versions%2C+%3E+0.2%25%2C+Firefox+ESR%2C+not+dead%2C+not+op_mini+all%2C+not+kaios+%3E+0%2C+not+and_uc+%3E+0%2C+not+and_qq+%3E+0). 

Alternatively, to list the browser versions supported by a specific configuration file, you can open a terminal at the root of any project including a `.browserslistrc` file and execute the following command:

```bash
pnpx browserslist
```
